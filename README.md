# 💱 Курсы валют и металлов

**Настольное приложение для просмотра данных Банка России, сравнения курсов и расчёта стоимости портфеля.**

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| Валюты | Посмотреть 16 валют, изменение между последними доступными значениями и мини-графики |
| Металлы | Посмотреть золото, серебро, платину и палладий; цены указаны в рублях за грамм |
| График | Выбрать инструмент и период, включить сравнение с предыдущим периодом |
| Экспорт | Сохранить график в PNG и данные выбранного основного ряда в CSV |
| Конвертер | Пересчитать сумму между рублями, валютами и металлами |
| Портфель | Ввести количество валюты и граммы металлов, получить оценку стоимости в рублях |

В коде также предусмотрены тёмное оформление, кэш ответов, фоновая загрузка карточек и графиков, обновление каждые 10 минут и уведомления о достижении заданного порога курса валюты.

> Статус: учебная версия в разработке. Список отражает возможности исходного кода; полная проверка интерфейса и расчётов ещё требуется.

## Быстрый запуск

Потребуются **Python 3.10 или новее**, Tkinter, графическая среда и доступ к интернету для загрузки данных. Рекомендуемая версия Python пока не означает проверку на всех ОС и версиях.

### 1. Скачать проект

Нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив. Либо используйте Git:

```bash
git clone https://github.com/IlyaTest1/-.git cbr-dashboard
cd cbr-dashboard
```

Откройте терминал в папке с `main.py`.

### 2. Создать окружение и запустить

**Windows (PowerShell или командная строка):**

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

**macOS / Linux:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Активировать окружение отдельно не требуется: команды используют его интерпретатор напрямую.

### Если не запускается

- **Нет Tkinter / ошибка `_tkinter`:** проверьте его командой `python3 -m tkinter` (Windows: `py -3 -m tkinter`). Должно открыться небольшое окно. Для Ubuntu/Debian установите `sudo apt install python3-tk python3-venv`. На Windows и macOS используйте сборку Python с поддержкой Tcl/Tk.
- **Нет requests или matplotlib:** выполните установку из `requirements.txt` тем же интерпретатором, которым запускаете приложение.
- **Нет данных:** дождитесь загрузки, проверьте интернет и нажмите `Ctrl+R`. Сервис ЦБ может отвечать с задержкой.
- **Окно не появляется на сервере:** приложению нужна графическая среда рабочего стола.

## Как пользоваться

1. Откройте приложение и дождитесь загрузки курсов.
2. На вкладках «Валюты» и «Металлы (ЦБ)» изучите карточки инструментов.
3. На вкладке «График» выберите валюту или металл и период. При необходимости включите сравнение, затем экспортируйте график или данные.
4. В «Конвертере» задайте сумму, исходную и конечную единицы и нажмите «Пересчитать».
5. В «Портфеле» укажите количество валюты и массу металлов в граммах, затем нажмите «Пересчитать портфель».
6. Кнопка «Пороги» позволяет настроить уведомления для валют.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+R` | Обновить данные |
| `Ctrl+1` … `Ctrl+5` | Перейти к соответствующей вкладке |

## Данные и расчёты

Приложение обращается к [Банку России](https://www.cbr.ru/):

- `XML_daily.asp` — текущие курсы валют;
- `XML_dynamic.asp` — история курсов;
- `XML_valFull.asp` — справочник валют;
- `DailyInfoWebServ/DailyInfo.asmx`, метод `DragMetDynamic` — история цен металлов.

Курсы валют приводятся к **одной единице валюты**: значение ЦБ делится на номинал. Стоимость позиции портфеля — количество × цена в рублях. Формула конвертации: сумма × рублёвая цена исходной единицы / рублёвая цена конечной единицы.

Данные публикуются по расписанию ЦБ; последние доступные значения могут относиться к разным датам. Обновление приложения каждые 10 минут не означает появления нового курса с такой частотой.

## Структура проекта

```text
.
├── main.py           # Интерфейс, запросы к ЦБ, графики и расчёты
├── requirements.txt  # Внешние зависимости Python
├── README.md         # Описание и инструкции запуска
├── CONTRIBUTING.md   # Порядок совместной работы и ручной проверки
└── .gitignore        # Исключения для локальных файлов
```

Файл `main.py` ранее назывался `1.py`; при переименовании содержимое сохранено.

Настройки и служебные данные сохраняются относительно домашней папки пользователя, в том числе на Windows:

| Назначение | Путь |
| --- | --- |
| Настройки и пороги | `~/.config/cbr_app/config.json` |
| Кэш ответов | `~/.cache/cbr_app/` |
| Журнал ошибок | `~/.local/share/cbr_app/app.log` |

PNG и CSV сохраняются в выбранное пользователем место.

## Ограничения и планы

- [ ] Учесть изменение цен металлов в дневной динамике портфеля: сейчас для металла предыдущее значение не передаётся в расчёт.
- [ ] Вынести сетевые запросы пересчёта портфеля из потока интерфейса, чтобы окно не зависало при ожидании ответа.
- [ ] Сравнивать периоды по границам дат: сейчас предыдущая выборка делится пополам по количеству записей.
- [ ] Уточнить название «Всё время»: в текущем коде это последние 3650 дней, а «Месяц» и «Год» — 30 и 365 дней.
- [ ] Проверить приложение на целевых компьютерах, сверить расчёты вручную и добавить реальные скриншоты.

Порядок проверки перед демонстрацией описан в [CONTRIBUTING.md](CONTRIBUTING.md).
